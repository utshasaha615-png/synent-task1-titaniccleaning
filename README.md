# SYNENT Task 1 - Titanic Data Cleaning

## 📌 Project Overview

This project is part of my Data Science internship at SYNENT.

The objective of this task is to perform data cleaning and preprocessing on the Titanic dataset and prepare the data for further analysis and machine learning.

## 📊 Dataset

The Titanic dataset contains information about passengers, including:

- Passenger ID
- Passenger Class
- Name
- Sex
- Age
- Number of Siblings/Spouses
- Number of Parents/Children
- Ticket
- Fare
- Cabin
- Embarked
- Survival Status

## 🛠️ Tools and Technologies

- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn

## 🔍 Data Cleaning Steps

The following steps were performed:

1. Loaded the Titanic dataset.
2. Inspected the dataset structure and information.
3. Checked for missing values.
4. Handled missing values.
5. Checked for duplicate records.
6. Cleaned and preprocessed the dataset.
7. Performed basic data inspection.
8. Saved the cleaned dataset as `Titanic_Cleaned.csv`.

## 📁 Files in this Repository

- `Synent_Task1_Titanic_Data_Cleaning.ipynb` - Google Colab/Jupyter Notebook containing the complete data cleaning process.
- `Titanic_Cleaned.csv` - Cleaned Titanic dataset.

## 🎯 Outcome

The raw Titanic dataset was successfully cleaned and prepared for further exploratory data analysis and machine learning tasks.
